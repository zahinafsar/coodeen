## Overview

The terminal toggle in the preview toolbar opens a tabbed shell pane below the preview. It uses [SwiftTerm](https://github.com/migueldeicaza/SwiftTerm), a native terminal emulator backed by a real PTY. `Cmd+J` toggles it.

## Tabs

- One tab per project directory. Switching to a session whose directory already has a tab activates that tab; switching to a new directory spawns a new tab.
- Each tab keeps its own terminal and PTY for its lifetime — buffer scrollback, running processes, and history persist across tab switches.
- The tab strip has an X to close a tab and a `+` to spawn an extra tab in the current directory (e.g. for running multiple processes).

## Persistence

Shells keep running when you collapse the terminal or hide the right panel, and their output is still there when you reopen it.

## Details

- Shell is your `$SHELL` as a login shell, spawned in the tab's project directory.
- Terminal reports `xterm-256color` and resizes with the panel.
- Processes are terminated when you close a tab or quit the app.

## Agent Access

Opencode's `bash` tool can run shell commands directly; the integrated terminal is for when you want to type them yourself.
