## Download

The homepage serves the native macOS build for Apple Silicon. It requires macOS 14 Sonoma or later.

| Platform | Download |
|----------|----------|
| macOS (Apple Silicon) | [Coodeen-mac-arm64.dmg](https://github.com/zahinafsar/coodeen/releases/latest/download/Coodeen-mac-arm64.dmg) |

Other artifacts (if any) are listed under [all releases](https://github.com/zahinafsar/coodeen/releases).

## Install (macOS)

1. Open the `.dmg` and drag **Coodeen** to Applications.
2. Clear the Gatekeeper quarantine attribute so the unsigned app can launch:

   ```bash
   xattr -cr /Applications/Coodeen.app
   ```

3. Open Coodeen from Applications.

## Add a Provider Key

1. Click the **gear icon** in the top-right of the toolbar (or press `Cmd+,`) to open Settings.
2. Click **Add provider**, pick **Anthropic**, **OpenAI**, **Google**, or **Z.AI**, and paste its API key.
3. Click **Connect**. The key is stored in opencode's auth store at `~/.local/share/opencode/auth.json`.

The dialog also has a **Custom** option for OpenAI-compatible endpoints (Ollama, local model servers, etc.). Any other provider that opencode supports can be wired in by editing `auth.json` directly.

## Pick a Project Folder

Click **Select folder** under the composer and choose your repo. Every opencode request in the session is scoped to that directory.

## First Prompt

1. Point the preview panel at your dev server (default `http://localhost:3000`).
2. Type a request in the composer — "explain the router", "add dark mode", whatever.
3. Watch tool calls render inline as the agent reads and edits files.
4. Click an element in the preview to screenshot it and attach the image to the next message.

## Optional: Custom Action Buttons

Drop a `coodeen.json` in your project root:

```json
{
  "actions": [
    { "label": "Dev", "script": "bun run dev" },
    { "label": "Test", "script": "bun run test" }
  ]
}
```

Each entry shows up in the top bar and runs `script` via `sh -c` in the project directory, with `.env` loaded.
